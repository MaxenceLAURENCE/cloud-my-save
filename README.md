# cloud-my-save 

### OBJECTIF : ajouter un système de sauvegarde cloud pour les jeu vidéo ne disposant pas de cette fonctionalité. 

Exemple de jeu : Sims 4 / Scrap mecanic / The Long Drive / Minecraft ... 

**ROADMAP** : 
- [ ] Backend : 
    - [ ] OAuth avec google drive 
    - [ ] Exporter une sauvegarde 
    - [ ] Importer une sauvegarde 
    - [ ] Gestion des version (possible conflit) 
    - [ ] Plusieur jeu en même temps 

- [ ] Frontend : 
    - [ ] Bouton importer / exporter 
    - [ ] Séléction du jeu 
    - [ ] Tutoriel?
